AGEPRO Projection Examples

The following set of examples is provided to illustrate projection options and features of the software. These projections use actual fishery data but are for the purposes of illustration only.

Example 1

The first example is a fishing mortality and landings quota projection for Acadian redfish. The time horizon is 2004-2009. The fishery is comprised of two fleets that have identical fishing mortality rates in 2004, identical quotas in 2005, and fishing mortality rates that differ by 2-fold during 2006-2009. This is standard projection analysis with 1000 bootstraps and 100 simulations per bootstrap based on an ADAPT-VPA stock assessment analysis. The model also outputs an R dataframe named Example1.rdat.
